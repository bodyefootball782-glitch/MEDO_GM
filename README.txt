MEDO WEBSITE — QUICK SETUP

1) Put all files in the same folder:
   index.html
   style.css
   script.js
   background-pc.mp4       (landscape video for PC)
   background-mobile.mp4   (portrait video for phones)
   music.mp3               (song)
   gta.png
   gta2.png
   gta3.png
   gta4.png
   gta5.png
   gta6.png

2) Open index.html to preview (or use VS Code Live Server).
3) Upload the folder/repository to GitHub and deploy it on Vercel.

NOTES
- Background videos are muted, blurred, looping, and switch by screen width.
- Music starts only after the visitor presses "ادخل لعالمي" because browsers block autoplay audio.
- Donation currently opens the phone dialer with 01270087040. If you want a payment link later, replace the href in index.html.
- Replace the six image files while keeping their exact filenames.
- If the video looks too dark/bright, adjust brightness in the .bg-video rule in style.css.
